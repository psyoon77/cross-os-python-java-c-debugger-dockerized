vs-code microsoft + docker - debugger and project setting

0 open the project in vs code
1 make sure that
    onboarding-mac/.devcontainer/devcontainer.json exists
2 command (or control) + shift + x
3 type dev containers and remote development extensions by microsoft
4 command (or control) + shift + p
5 type dev containers: reopen in container
6 vs code will reopen using the container
7 note that all python, c, and java are managed by conda
8 inside the container
pwd
ls
which python
python --version
which javac
javac -version
which gcc
gcc --version
which gdb
gdb --version
9 to rebuild docker after changes
10 command (or control) + shift + p
11 type dev containers: rebuild container
or dev containers: rebuild and reopen in container
